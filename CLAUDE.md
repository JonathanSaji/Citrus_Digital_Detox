# Digital Detox Project

This is a Java application.

## Rules
- Use Java and JavaFX.
- Keep the existing architecture unless there is a good reason to change it.
- Do not rewrite unrelated classes.
- Prefer simple, readable code over unnecessarily advanced solutions.
- Explain significant changes after implementing them.
- Do not add external libraries unless I approve them first.
- Preserve existing functionality.
- Before large changes, explain the files you plan to modify.
- After changes, compile/run the project and fix errors caused by the changes.
